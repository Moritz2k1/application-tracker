# Paperplane

A macOS app to track your job applications and write the HTML cover letters and CVs you send with them.

## Features

- **Applications by year:** company, job title, date, status and document in one table.
- **Built-in HTML editor:** syntax highlighting, linting and formatting, with a live preview.
- **CV library:** keep your CVs with as many versions as you need.
- **Images, PDF and browser:** add images, export as A4 PDF or open the page in your browser.
- **Private:** everything stays on your Mac. No account, no cloud.

## Installation

1. Download the latest version from [Releases](../../releases), unzip it and move **Paperplane** to your Applications folder.
2. The app isn't signed with an Apple Developer ID, so macOS blocks it on first launch. Open it once, then click **Open Anyway** in **System Settings → Privacy & Security**.

Requires macOS 26.0 or later.

## Usage

- **Add an application:** pick a year in the sidebar and click **+** (⌘N).
- **Write the document:** double-click an application, then choose **New Document** or **Import HTML…**.
- **Manage CVs:** select **CVs** in the sidebar. **New Version** duplicates a CV so you can adapt it.
- **Add images:** use **Images → Add Images…** and reference them by file name, e.g. `<img src="photo.jpg">`.
- **Share:** **Export PDF** (⇧⌘E) or **Open in Browser**.

Changes are saved automatically.
